Este es el repositorio de software asociado al *Trabajo de Fin de Grado (TFG)* del Grado en Desarrollo de Videojuegos de la Universidad Complutense de Madrid titulado 'MBTI-Motion: Animación adaptativa mediante aprendizaje profundo para personajes de videojuego con personalidad y emociones}' y realizado durante el curso 2025-2026 bajo la dirección del Prof. Federico Peinado Gil.

## Descripción

El presente TFG tiene como objetivo el desarrollo e implementación de un plugin para Unreal Engine que permite la creación de un 'motor psicológico' para los diferentes Metahumans. 
Esta herramienta busca aprovechar las capacidades de animación de Unreal Engine, junto con las de creación y modificación de Metahumans, ofreciendo al jugador una interacción con los NPCs lo más realista posible. El sistema permite comprobar los diferentes cambios de emociones basándose en la personalidad del personaje y el entorno al que se enfrente, reflejando todo ello dinámicamente mediante la animación facial y corporal.

## Description
This Final Degree Project aims to develop and implement a plugin for Unreal Engine that enables the creation of a 'psychological engine' for different Metahumans.
This tool seeks to leverage Unreal Engine’s animation capabilities, together with its Metahuman creation and modification features, in order to provide players with interactions with NPCs that are as realistic as possible. The system makes it possible to observe different emotional changes based on the character’s personality and the environment they face, dynamically reflecting all of this through facial and body animation.
